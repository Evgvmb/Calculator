    Автономное PWA-приложение CableCalc Pro (GitHub Pages / PWABuilder)

    Весь проект собран в один автономный файл index.html в корне репозитория без внешних зависимостей, фреймворков и сборщиков. Он открывается напрямую на GitHub Pages из корня ветки main и работает 100% без интернета.

    Рядом в корне находятся manifest.json, sw.js и PNG-иконки (pwa-192x192.png, pwa-512x512.png, pwa-maskable-512x512.png, apple-touch-icon.png) для мгновенной компиляции в Android APK через сервис PWABuilder.com.
